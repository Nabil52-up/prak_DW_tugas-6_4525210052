## 1. Mini Design Guide

Mini design guide digunakan sebagai pedoman visual untuk menjaga konsistensi desain pada setiap bagian website.

### Palet Warna

| Nama | Kode Warna | Penggunaan |
| :--- | :--- | :--- |
| Hijau Hutan | `#19483D` | Logo, judul, tombol utama, dan footer |
| Krem | `#F5F2E8` | Latar halaman dan beberapa bagian konten |
| Putih | `#FFFFFF` | Latar kartu dan area konten |
| Abu-abu | `#718078` | Teks pendukung dan informasi tambahan |

### Tipografi

Menggunakan font **Arial** sebagai font utama agar tampilan sederhana, konsisten, dan mudah dibaca.

| Elemen | Penggunaan |
| :--- | :--- |
| Judul utama | Ukuran besar dan tebal |
| Judul bagian | Ukuran sedang dan tebal |
| Isi | Ukuran normal untuk kenyamanan membaca |
| Label | Ukuran kecil untuk informasi tambahan |

### Komponen UI

- **Tombol:** Menggunakan bentuk sederhana dengan sudut membulat.
- **Kartu:** Menampilkan informasi program dan fasilitas secara terstruktur.
- **Navigasi:** Berisi menu utama untuk memudahkan pengunjung menjelajahi website.
- **Placeholder gambar:** Digunakan pada wireframe sebagai gambaran posisi gambar sebelum desain final.
- **Layout responsif:** Menyesuaikan susunan konten untuk layar desktop dan mobile.

## 2. Studi Kasus

Sekolah Ambaruwo membutuhkan desain landing page yang dapat memperkenalkan identitas sekolah, program pendidikan, fasilitas, dan informasi pendaftaran secara jelas.

### Identitas Visual
Warna hijau hutan dan krem dipilih untuk memberikan kesan hangat, nyaman, dan tepercaya. Elemen visual dibuat sederhana agar pengunjung dapat fokus pada informasi utama.

### Hierarki Informasi
Halaman dimulai dengan judul utama dan informasi pengenalan sekolah, dilanjutkan dengan program pendidikan, fasilitas, ajakan untuk menghubungi sekolah, dan footer.

### Tombol Utama
Tombol *Tanya Pendaftaran* digunakan sebagai ajakan bagi pengunjung yang ingin memperoleh informasi lebih lanjut mengenai sekolah.

### Adaptasi Mobile
Pada tampilan mobile, navigasi disederhanakan, kartu disusun vertikal, dan tombol dibuat lebar agar konten lebih mudah dibaca serta digunakan pada layar kecil.

## 3. Wireframe Desktop

Wireframe desktop merupakan rancangan awal yang berfokus pada struktur halaman dan penempatan elemen sebelum diberikan warna serta detail visual.

Bagian yang dirancang meliputi:

- **Header:** Logo sekolah dan navigasi utama.
- **Hero:** Judul utama, teks pengantar, tombol, dan area gambar.
- **Tentang Program:** Informasi singkat mengenai program pendidikan.
- **Program:** Kartu yang menampilkan informasi program.
- **Fasilitas:** Area gambar dan informasi fasilitas sekolah.
- **CTA:** Ajakan untuk menghubungi sekolah.
- **Footer:** Informasi dan navigasi tambahan.

## 4. High-Fidelity Mockup Desktop

Mockup high-fidelity merupakan pengembangan wireframe dengan menerapkan warna, tipografi, tombol, kartu, dan elemen visual yang lebih mendekati tampilan website akhir.

Pengembangan desain meliputi:

- Penerapan warna hijau hutan dan krem.
- Penggunaan tipografi yang konsisten.
- Penyesuaian bentuk dan jarak antarkomponen.
- Penggunaan gambar untuk memperjelas informasi visual.
- Penyusunan bagian halaman agar terlihat lebih rapi dan mudah dipahami.

## 5. Wireframe Mobile

Wireframe mobile merupakan rancangan awal untuk tampilan website pada layar ponsel. Struktur konten disesuaikan agar tetap mudah dibaca dan digunakan.

Penyesuaian yang dilakukan meliputi:

- Header menggunakan logo dan menu hamburger.
- Konten hero disusun secara vertikal.
- Tombol disesuaikan dengan lebar layar.
- Kartu program disusun dalam satu kolom.
- Gambar fasilitas ditampilkan secara berurutan.
- CTA dan footer mengikuti alur halaman dari atas ke bawah.
